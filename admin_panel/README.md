# HizmetBirleştir Admin Paneli

Modern, responsive ve vanilla HTML/CSS/JS ile hazırlanmış admin paneli prototipi.

## Çalıştırma
index.html dosyasını tarayıcıda açmanız yeterlidir.

## Sonraki entegrasyon
API / backend bağlantısı eklenerek kullanıcılar, hizmet verenler, talepler, siparişler, ödemeler, komisyonlar, bildirimler ve roller gerçek verilerle çalıştırılabilir.
